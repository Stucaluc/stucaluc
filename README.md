## Featured work

### 🤖 Nexo — AI personal assistant on WhatsApp
Multimodal assistant (text, voice and photo) where an AI agent with tool use runs 70+ actions: expenses in multiple currencies, recurring reminders, Google Calendar, receipt reading with computer vision and PDF proposals — always asking for approval before sending anything.

`Node.js` `PostgreSQL` `Docker` `Evolution API` `Gemini / Anthropic APIs` · retry with backoff, daily self-test, 80+ unit tests, prompt-injection mitigation

### 🔗 [URL Shortener with Analytics](https://github.com/Stucaluc/URL-shortener-com-analytics)
Short links with custom aliases and expiration, plus a dashboard with clicks, unique visitors, referrers, browsers, devices and countries. Privacy by design: no raw IPs stored, only an HMAC hash.

`TypeScript` `Fastify` `PostgreSQL` `Chart.js` `Docker` · API key auth, rate limiting, Zod validation, CI with GitHub Actions

### 🎪 Event Suppliers Marketplace *(in development)*
Subscription B2B marketplace connecting event producers and suppliers: search by category and city, portfolios, reviews and quote requests.

<img src="./assets/eventos-b2b-home.webp" width="100%" alt="Eventos B2B home page: supplier search and sign-up call to action"/>

### 🐾 Pet shop management platform *(client project, private)*
Cash flow, scheduling, inventory and point of sale in one system, replacing processes that were done by hand. `PHP` `JavaScript` `MySQL` `Bootstrap` `REST API`
